## Overview

Algorave is a live audio-visual performance practice built around algorithmic, code-driven music and imagery. The project lives on two sides: the live visual identity and performance concept of the Algorave night, and the technical tools that make it run — a custom sound engine and an approachable no-code interface for performing with it.

## Visual & motion concept

The visual language leans on generative geometry reacting to audio in real time. Patterns mutate with the tempo and energy of the track rather than following a fixed script, giving each performance its own spontaneous composition.

## Sound engine & no-code tool

The dev side of the project pairs a custom sound engine with a no-code performance tool, so the Algorave experience isn't locked behind traditional code. The interface turns the underlying audio system into a playable instrument — musicians can trigger, layer, and manipulate sounds without writing, making algorithmic music performance more approachable while the engine handles the heavy lifting.
