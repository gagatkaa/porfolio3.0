## Overview

Grid & Form is a comprehensive editorial design system developed for a contemporary art publication. The system emphasizes modularity, allowing each issue to maintain a cohesive visual identity while adapting to diverse content formats.

## System architecture

The grid system uses a 12-column flexible layout with strict vertical rhythm rules. Typography is built around a single typeface family with distinct weights and widths serving different hierarchical levels.

## Design principles

- Modular grid with adaptive breakpoints
- Monochromatic palette with selective neon accents
- Generous white space for visual breathing room
- Image-first storytelling with typographic restraint
- Consistent rhythm across spreads and sections

## Outcome

The system has been applied across five issues, each maintaining visual coherence while allowing for distinct editorial voices.
