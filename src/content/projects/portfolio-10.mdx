## Overview

Portfolio 1.0 was the first full version of my site — the one you're looking at, or the version that came before it. The goal was a space that felt like both a portfolio and an interactive experiment, where the presentation matched the work it was hosting.

## Approach

The project pairs a desktop-inspired visual direction with real interactivity: a terminal, taskbar shortcuts, and window-like project sections. Each piece of the UI is there to make browsing the work feel more like exploring a system than scrolling a page.

## Product choices

- **Astro** for a fast, content-driven build
- A **content-collection** structure so projects are managed as data rather than hard-coded
- **Retro desktop aesthetics** applied with restraint, keeping readability first
