## Overview

Void is a brand identity project for a conceptual art space that explores themes of absence, emptiness, and negative space. The visual language strips away ornamentation to its bare essentials.

## Brand philosophy

The identity embraces silence as a design material. Every element is justified by purpose — nothing exists purely for decoration. The logomark uses a single continuous line that folds into negative space, representing the void as both absence and potential.

## Visual system

- Custom wordmark with modified letter spacing
- Extended negative space as a core compositional tool
- Monochrome palette with strategic use of void (blank) areas
- Generative typographic posters updated weekly
- Motion system based on slow fades and long holds

## Collateral

The system includes a visual identity guide, stationery, signage, digital templates, and a motion library for social media presence.
