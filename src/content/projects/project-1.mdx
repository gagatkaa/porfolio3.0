## Overview

Neon Frequencies is an experimental web-based music visualizer that translates live audio input into generative visual landscapes. Built with Three.js and custom GLSL shaders, it creates a unique audio-reactive experience where sound waves morph into neon geometries.

## Process

The project started as an exploration of real-time audio analysis and vertex manipulation. Using the Web Audio API's AnalyserNode, frequency data is mapped to shader uniforms that control color, displacement, and particle behavior.

## Key features

- Real-time audio analysis with FFT
- Custom GLSL fragment and vertex shaders
- Responsive particle systems driven by frequency bands
- Camera controls for immersive viewing
- Session recording and export capability
